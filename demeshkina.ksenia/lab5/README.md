# Лабораторная работа 5

## Задание

Вариант 3

Создать слайдер на главной странице магазина состоящий из карточки книги.
Карточка должна содержать обложку книги, название, рейтинг, описание и цену.

Функционал слайдера:

- кнопки далее и назад;
- подпись текста к каждому слайду;
- вывод номера и максимального количества (1/3,2/3,/3/3);
- пагинация (при клике - переключается на нужный слайд).

## Реализация

Компоненты: App — корневой компонент: заголовок, слайдер книг и всё, что с ним
связано; Slider — компонент слайдера: карточка книги, подпись к слайду, кнопки
«Назад» и «Далее», счётчик слайдов и пагинация; карточка книги (обложка,
название, рейтинг, описание, цена) выводится внутри Slider по данным текущей
книги из массива books.

Состояние: current — номер текущего слайда. Нумерация начинается с 0, то есть
первая книга имеет номер 0. Текущая книга при каждой отрисовке вычисляется из
состояния: берётся элемент массива books с номером current. При изменении
current React заново отрисовывает компонент, и на экране появляется другая
книга.

Сценарии: при открытии главной страницы показана первая книга: обложка,
название, рейтинг, описание, цена и подпись к слайду, а между кнопками выводится
номер 1/3; клик по кнопке «Далее» показывает следующую книгу, номер слайда
обновляется, а на последнем слайде кнопка возвращает к первому; клик по кнопке
«Назад» показывает предыдущую книгу, а на первом слайде кнопка переносит на
последний; клик по любой точке пагинации сразу открывает соответствующую книгу;
номер слайда и общее количество (1/3, 2/3, 3/3) обновляются при каждом
переключении.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
