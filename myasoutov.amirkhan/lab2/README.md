# Лабораторная работа 2

## Задание

Вариант 35. Написать функцию findMissingNumber(arr), находящую пропущенное число
в массиве целых чисел от 1 до N (одно пропущено).

## Реализация

Решение реализовано с использованием формулы суммы арифметической прогрессии S =
N * (N + 1) / 2. Фактическая сумма элементов массива вычисляется с помощью
метода reduce. Пропущенное число находится как разность ожидаемой и фактической
суммы. Исходный массив не мутирует. Функция экспортируется именованным экспортом
findMissingNumber.
