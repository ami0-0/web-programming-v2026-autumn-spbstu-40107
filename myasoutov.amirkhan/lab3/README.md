# Лабораторная работа 3

## Задание

Вариант 35. Реализуйте функцию findMedian(arr), которая вычисляет медиану
числового массива.

## Реализация

Массив копируется с помощью spread-оператора для предотвращения мутации
аргумента, после чего сортируется по возрастанию числовым компаратором. Если
длина отсортированного массива нечётная, возвращается центральный элемент. Если
чётная — вычисляется среднее арифметическое двух центральных элементов. Функция
экспортируется именованным экспортом findMedian.
