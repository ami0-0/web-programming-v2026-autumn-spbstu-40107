# Лабораторная работа 4

## Задание

Вариант 35. Создать класс BlogPost и функции для работы с массивом постов
(группировка, фильтрация). Разработать пользовательский интерфейс для
добавления/удаления постов, тегов и комментариев.

## Реализация

Модель (`model.js`) содержит класс `BlogPost` и чистые функции для работы с
массивом постов (Map, Set, filter). Интерфейс (`main.js`) манипулирует DOM в
соответствии с контрактом `data-testid`. Все изменения состояния (добавление,
удаление постов, комментариев, тегов) происходят асинхронно с имитацией задержки
(`setTimeout` обёрнутый в `Promise`). Данные реактивно сохраняются в
`localStorage` и восстанавливаются при перезагрузке страницы.

## Запуск

Откройте `index.html` в браузере с помощью локального сервера.
